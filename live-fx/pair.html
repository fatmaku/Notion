Zum Panel

Hilfe – so klappt's
  1. Am PC: LiveFX starten, im Panel oben auf „📱 Handy“ tippen (oder Start-Assistent Schritt 1).
  2. QR-Code mit der Handy-Kamera scannen – oder den 6-stelligen Code hier eintippen.
  3. Handy und PC müssen im selben WLAN sein. Unterwegs/mobile Daten: im Panel „Internet-Link starten“.
  4. Code abgelaufen? Ein Code gilt 10 Minuten und nur einmal – im Panel einfach einen neuen anzeigen.
