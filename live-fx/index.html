Externe API (Stream Deck, Streamer.bot, Whisper …)

⚠️ Server nötig: Starte node server.js und öffne das Panel über http://127.0.0.1:8787/.


        
    
          
  • Stream Deck / Streamer.bot: HTTP-Aktion POST /api/fire mit {"id":"wow"} und dem Bearer-Token – oder {"trigger":{…}} für einen Ad-hoc-Effekt.
    • 
          
  • Externe Spracherkennung (Whisper, Handy-App): POST /api/transcript mit {"text":"…","final":true} und oben „Extern“ als Spracherkennung wählen.
    • 
          
  • Lautstärke: POST /fire mit {"type":"volume","volume":0.5}.

OBS / Streamlabs einrichten

        

          1. Terminal: node server.js im Ordner live-fx – dann dieses Panel über http://127.0.0.1:8787/ öffnen.

          2. OBS → Quelle hinzufügen → Browser → URL http://127.0.0.1:8787/overlay.html (Querformat) oder http://127.0.0.1:8787/overlay.html?layout=portrait (Hochkant, hält den Chat-Bereich unten frei). Breite/Höhe wie dein Canvas (1920×1080 oder 1080×1920).

          3. In der Browser-Quelle „Audio über OBS steuern“ aktivieren, damit die Sounds im Stream landen.

          4. Dieses Panel im normalen Browser offen lassen und Mikro starten. Fertig.
