    OBS / Streamlabs einrichten (für echte Streams)
    
        
    
          1. Terminal: node server.js im Ordner live-fx – dann dieses Panel über http://127.0.0.1:8787/ öffnen.
    
          2. OBS → unten bei Quellen auf + → Browser → URL http://127.0.0.1:8787/overlay.html (Querformat) oder http://127.0.0.1:8787/overlay.html?layout=portrait (Hochkant, hält den Chat-Bereich unten frei). Breite/Höhe wie dein Canvas (1920×1080 oder 1080×1920).
    
          3. Die Browser-Quelle in der Liste über die Kamera schieben (Pfeil ▲), sonst verdeckt die Kamera die Memes.
    
          4. Doppelklick auf die Browser-Quelle → „Audio über OBS steuern“ anhaken → im Audiomixer erscheint „LiveFX Overlay“.
    
          4b. Dein Mikrofon als eigene Quelle: + → Audioeingabeaufnahme → Mikro wählen. Desktop-Audio stumm schalten, sonst kommt der Panel-Tab doppelt rein (Echo).
    
          5. Test: hier Taste 1 drücken → Karte im OBS-Vorschaubild, Mixer-Balken zuckt. Dann „Aufnahme starten“ bzw. „Stream starten“.
