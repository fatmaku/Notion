🚗 Window Blaster – Anleitung

Für MacBook (macOS 11 Big Sur oder neuer) + iPhone oder Android-Handy · Version {{.Version}}

KurzfassungMacBookiPhoneAndroidOfflineWenn es nicht startet
Braucht das Spiel Internet? Nein. Der Mac schickt das Spiel einmal über dein WLAN aufs Handy. Danach läuft es auf dem Handy komplett ohne Mac und ohne Internet – im Auto, Zug oder Bus. Am besten richtest du es zu Hause ein.

Kurzfassung – in 6 Schritten

  1. Entpacken: Doppelklick auf WindowBlaster.zip (Safari entpackt oft schon von selbst – dann liegt der Ordner bereits in „Downloads“). Es entsteht der Ordner WindowBlaster (oder „WindowBlaster 2“, wenn es schon einen gibt – das ist egal). Zieh ihn auf den Schreibtisch.
    Hast du noch eine ältere Version (Ordner „WindowBlaster-Mac…“)? Die darf in den Papierkorb. Das Handy richtest du einmal neu ein (Schritt 5); ein altes Profil „Caddy Local Authority“ kannst du am iPhone unter Einstellungen → Allgemein → VPN und Geräteverwaltung löschen.
  2. Erster Start (nur einmal so): Programm Terminal öffnen (⌘+Leertaste, „Terminal“ tippen, ↩). Tippe bash und ein Leerzeichen. Zieh dann die Datei Start-Window-Blaster.command aus dem Ordner ins Terminal-Fenster und drück ↩.
    Fragt der Mac nach Zugriff auf „Schreibtisch“ oder „Downloads“ → Erlauben. Ab dem zweiten Mal genügt ein Doppelklick auf die Startdatei – nach jedem neuen Download (Update) aber wieder einmal über das Terminal starten.
  3. Verbindungsseite: Im Browser öffnet sich „Window Blaster – Handy verbinden“ mit einem großen QR-Code. Das Terminal-Fenster offen lassen und das MacBook aufgeklappt (am besten am Strom), bis das Handy „Offline bereit ✓“ zeigt – zugeklappt schläft der Mac ein.
  4. Handy verbinden: Handy ins gleiche WLAN wie den Mac, mobile Daten am besten kurz aus. Kamera-App öffnen, QR-Code scannen, auf den Link tippen.
  5. Zertifikat (einmalig): Die Handy-Seite führt dich durch 2–3 kurze Schritte. Wenn sie grün „vertraut dem Mac“ zeigt → Spiel öffnen.
  6. Als App speichern: Spiel zum Home-Bildschirm hinzufügen, von dort öffnen und warten, bis „Offline bereit ✓“ erscheint. Fertig!

MacBook – ausführlich

Erster Start

macOS blockiert Programme aus dem Internet, die nicht im App Store sind („Apple konnte nicht überprüfen …“). Der Start über das Terminal umgeht das sicher – nur für diesen Ordner: Die Startdatei entfernt beim ersten Lauf die Sperre für den Ordner WindowBlaster, danach geht auch der Doppelklick.

  1. Terminal öffnen: ⌘+Leertaste → „Terminal“ → ↩.
  2. bash tippen (mit Leerzeichen danach).
  3. Die Datei Start-Window-Blaster.command aus dem Finder ins Terminal-Fenster ziehen – der Pfad erscheint automatisch.
  4. ↩ drücken.

Im Terminal steht dann „Window Blaster läuft“, ein QR-Code und die Adressen. Gleichzeitig öffnet sich die Verbindungsseite im Browser.

Lieber per Doppelklick? Doppelklick auf Start-Window-Blaster.command → Meldung „nicht geöffnet“ → Fertig. Dann Apple-Menü (oben links) → Systemeinstellungen → Datenschutz & Sicherheit → rechts nach unten scrollen bis zum Abschnitt „Sicherheit“ → bei „Start-Window-Blaster.command wurde blockiert“ → Dennoch öffnen → Passwort oder Touch ID → nochmal Dennoch öffnen.

Am Mac spielen

Auf der Verbindungsseite ▶ Demo am Mac spielen – oder im Browser http://localhost:{{.HTTPPort}}/?demo=1. Der Mac zeigt eine simulierte Straße; das echte Spiel mit Autos vor dem Fenster braucht die Rückkamera des Handys.

Beenden

Terminal-Fenster schließen (oder ctrl+C). Der Mac wird nur zum Einrichten und für Updates gebraucht.

iPhone – ausführlich

  1. QR-Code scannen mit der Kamera-App → gelben Link antippen. Die Seite öffnet sich in Safari (wichtig: nur Safari kann Zertifikate installieren).
  2. 📄 Profil laden → Zulassen → Schließen. (Apple Watch gekoppelt? Bei der Gerätefrage iPhone wählen.)
  3. Innerhalb von 8 Minuten: Einstellungen öffnen → oben Profil geladen → Installieren (oben rechts) → Code → Installieren (oben rechts) → nochmal Installieren (unten) → Fertig. Das rote „Nicht überprüft“ ist normal.
    „Profil geladen“ nicht zu sehen? Einstellungen → Allgemein → VPN und Geräteverwaltung – oder Schritt 2 wiederholen.
  4. Einstellungen → Allgemein → Info → ganz unten Zertifikatsvertrauenseinstellungen → Schalter bei „Window Blaster Mac …“ ein → Fortfahren.
  5. Zurück zu Safari: Die Seite zeigt grün „Dein Handy vertraut dem Mac“ → ▶ Spiel öffnen.
  6. Im Spiel: Teilen ⬆︎ (iOS 26: erst ••• unten rechts, dann Teilen) → Zum Home-Bildschirm → „Als Web-App öffnen“ an lassen → Hinzufügen.
  7. Das neue Symbol auf dem Home-Bildschirm antippen (nicht Safari!) und warten, bis „Offline bereit ✓“ erscheint. Fertig.

Android – ausführlich

  1. QR-Code scannen (Kamera oder Google Lens) → Link in Chrome öffnen.
  2. 📄 Zertifikat herunterladen. Hinweis „kann nicht installiert werden“ ist normal.
  3. Einstellungen → ins Suchfeld „CA-Zertifikat“ → Treffer antippen → Trotzdem installieren → PIN (ohne Bildschirmsperre verlangt Android, eine einzurichten) → Datei WindowBlaster-Zertifikat.crt aus „Downloads“ wählen.
    Pixel: Sicherheit & Datenschutz → Weitere Sicherheitseinstellungen → Verschlüsselung & Anmeldedaten → Zertifikat installieren → CA-Zertifikat. Samsung: Sicherheit und Datenschutz → Weitere Sicherheitseinstellungen → Von Gerätespeicher installieren → CA-Zertifikat.
  4. Zurück zu Chrome: grün → ▶ Spiel öffnen.
  5. Menü ⋮ → App installieren → App öffnen → warten auf „Offline bereit ✓“.

Unterwegs & ohne WLAN

  • Ist das Spiel einmal als App installiert und zeigt „Offline bereit ✓“, braucht es weder Mac noch Internet.
  • Kein WLAN-Router in der Nähe (Auto, Ferienwohnung)? Der Mac kann selbst ein WLAN aufmachen: Systemeinstellungen → Allgemein → Teilen → bei Internetfreigabe auf ⓘ klicken → „Verbindung teilen von“: irgendein Anschluss, z. B. „Thunderbolt-Bridge“; „Für Geräte über“: WLAN einschalten → WLAN-Optionen …: Name und Passwort festlegen → OK → Internetfreigabe einschalten. Das Handy verbindet sich mit diesem WLAN des Macs – ganz ohne Internet (Android: mobile Daten dabei kurz ausschalten und „trotzdem verbunden bleiben“ bestätigen). Dann die Verbindungsseite am Mac neu laden (⌘+R) und den neuen QR-Code scannen.
  • Zug-, Hotel- und Gäste-WLANs blockieren oft die Verbindung zwischen Geräten. Dort lieber die Internetfreigabe nutzen – oder zu Hause einrichten.
  • Der Mac kann danach wochen- oder monatelang aus bleiben – das Spiel auf dem Handy läuft weiter.
  • Updates: Neue Zip entpacken und starten. Am Handy im selben WLAN die App im App-Umschalter nach oben wegwischen und neu öffnen – sie lädt die neue Version, startet sich einmal neu und behält Punkte, Freischaltungen und Offline-Daten. Die Versionsnummer steht unten auf dem Startbildschirm. Das Zertifikat muss nicht neu installiert werden.

Mit AR-Brille oder Headset

Display-Brille am Handy (XREAL, VITURE, Rokid, RayNeo): Brille per USB-C ans Handy (iPhone 15 oder neuer – nicht 16e, 17e, Air –, Android mit Bildausgabe über USB-C). Im Spiel 🕶️ Brillen & AR → Durchsicht-Modus einschalten → 🎯 Brille ausrichten: das blasse Kamerabild verschieben und zoomen, bis es über der echten Welt liegt. Ohne Durchsicht-Modus erscheint das Spiel einfach groß wie auf einer Leinwand.

Steuern ohne Hinschauen: „Handy als Touchpad“ einschalten (wischen = zielen, tippen = schießen) oder einen Bluetooth-Controller / eine Tastatur koppeln.

Headset (Meta Quest 3/3S, Galaxy XR, Pico 4 Ultra): Im Browser des Headsets dieselbe Adresse öffnen wie am Handy (sie steht unter dem QR-Code). Eine Zertifikatswarnung mit Erweitert → Weiter bestätigen. Dann 🕶️ Brillen & Headset (WebXR) → Runden im Headset spielen. Quest 3/3S: „Headset-Kameras“ erlauben (noch experimentell, sonst Demo); im Zug den Reisemodus einschalten. Im Auto unterstützt Meta das Tracking nicht.

Geht im Browser nicht: Ray-Ban Meta / Oakley Meta (kein Display, Kamera nur für native Apps) und Apple Vision Pro (kein AR mit Kamera in Safari).

Wenn es nicht startet

Was du siehstWas hilft
Doppelklick: „… wurde nicht geöffnet“ / „Apple konnte nicht überprüfen …“Erster Start über das Terminal (siehe MacBook), oder Systemeinstellungen → Datenschutz & Sicherheit → nach unten scrollen bis „Sicherheit“ → Dennoch öffnen. Gilt nach jedem neuen Download erneut.
Terminal: „Operation not permitted“Systemeinstellungen → Datenschutz & Sicherheit → Dateien und Ordner → Terminal → „Schreibtisch“ erlauben. Oder den Ordner WindowBlaster in deinen Benutzerordner verschieben (Finder → Menü „Gehe zu“ → „Benutzerordner“, oder ⇧+⌘+H) und von dort starten.
Terminal: „Der Ordner app fehlt“ / „Programm fehlt“ / „kein Zugriff“Hat der Mac nach Zugriff auf „Schreibtisch“ oder „Downloads“ gefragt und du hast „Nicht erlauben“ gewählt? Systemeinstellungen → Datenschutz & Sicherheit → Dateien und Ordner → Terminal → einschalten. Sonst: Ordner löschen, WindowBlaster.zip neu herunterladen und entpacken.
Terminal: „no such file or directory“Zwischen bash und dem Pfad fehlt das Leerzeichen. Neu tippen: bash, Leerzeichen, Datei hineinziehen, ↩.
Terminal: „Killed: 9“ / „Code 137“macOS hat das Programm gestoppt. Systemeinstellungen → Datenschutz & Sicherheit → nach unten scrollen → bei „windowblaster…“ Dennoch erlauben → Startdatei erneut starten. Hilft das nicht: Ordner löschen, Zip neu herunterladen und erster Start über das Terminal.
Terminal: „kein freier Port“Ein anderes Programm belegt die Ports. Mac neu starten und dann nur Window Blaster starten.
Terminal: „Datenordner … nicht beschreibbar“Im Benutzerordner fehlen Schreibrechte für „Library/Application Support“. Mac neu starten; hilft das nicht, im Finder (⇧+⌘+G, ~/Library/Application Support) → Ablage → Informationen → Freigabe & Zugriffsrechte → „Lesen & Schreiben“ für dich.
Terminal: „Window Blaster läuft bereits“Ein anderes Terminal-Fenster mit demselben Spiel ist noch offen – das ist in Ordnung, die Verbindungsseite öffnet sich trotzdem. Ist dort eine ältere Version offen, beendet der neue Start sie automatisch.
Terminal: „die alte Version läuft noch“Das andere Terminal-Fenster schließen (im Terminal ⌘+Q) und die Startdatei erneut starten.
Terminal: „macOS … ist zu alt“Window Blaster braucht macOS 11 (Big Sur) oder neuer: Apple-Menü → Über diesen Mac → Softwareupdate.
Handy-Einrichtung bricht ab / „Prüfe …“ bleibt hängenIst der Mac eingeschlafen? MacBook aufgeklappt lassen, am besten am Strom, und die Handy-Seite neu laden.
Mac fragt „Eingehende Netzwerkverbindungen akzeptieren?“Erlauben – sonst erreicht das Handy den Mac nicht.
Browser: „Diese localhost-Seite wurde nicht gefunden“ / „HTTP ERROR 404“ unter https://localhost:8443Das ist die Adresse der alten Version, deren Server oft noch im Hintergrund läuft. Die neue Startdatei beendet ihn automatisch – also einfach Start-Window-Blaster.command starten. Klappt das nicht: Mac neu starten und dann starten. Am Mac immer http://localhost:{{.HTTPPort}}/verbinden benutzen (http, ohne „s“, Port {{.HTTPPort}}).
Browser zeigt eine leere oder alte SeiteNeu laden (⌘+R). Hilft das nicht: http://localhost:{{.HTTPPort}}/?reset=1 öffnen – setzt den Spiel-Zwischenspeicher zurück (Punkte bleiben).
Handy öffnet die Seite nichtGleiches WLAN? VPN aus? Adresse genau mit http:// und :{{.HTTPPort}}? Auf der Verbindungsseite unter „Andere Adressen“ probieren. Gäste-/Zug-WLAN → Internetfreigabe. Android: WLAN des Macs gewählt, aber die Seite lädt nicht? Mobile Daten kurz ausschalten und bei „Keine Internetverbindung – trotzdem verbunden bleiben?“ auf Ja tippen. Samsung: Einstellungen → Verbindungen → WLAN → ⋮ → Intelligentes WLAN → „Zu mobilen Daten wechseln“ aus.
Handy-Seite bleibt gelb „Prüfe …“iPhone: Schalter in Zertifikatsvertrauenseinstellungen einschalten. Android: Zertifikat als CA-Zertifikat installieren. Dann Seite neu laden.
Keine Kamera-Abfrage im SpieliPhone: Einstellungen → Apps → Safari → Kamera → „Fragen“ (ältere iOS: Einstellungen → Safari → Kamera). Bei der Home-Bildschirm-App: App schließen und neu öffnen, dann „Erlauben“. Android: Chrome → Website-Einstellungen → Kamera.
„Offline bereit“ erscheint nichtDie App vom Home-Bildschirm öffnen, während der Mac-Server läuft und das Handy im selben WLAN ist. Auf dem Startbildschirm „Für offline vorbereiten“ tippen.
Spiel hakt oder friert einStartbildschirm → „Letzter Fehler“ → Kopieren und den Text an den Entwickler schicken.

Sicherheit & Datenschutz

  • Nur als Fahrgast spielen – nie am Steuer.
  • Die Kamera wird nur live auf dem Handy ausgewertet. Es wird nichts aufgenommen oder hochgeladen.
  • Das Zertifikat gilt nur für deinen eigenen Mac (es liegt in ~/Library/Application Support/WindowBlaster) und lässt sich am Handy jederzeit entfernen.
  • Der Mac-Server liefert nur den Ordner app aus und läuft nur, solange das Terminal-Fenster offen ist.
