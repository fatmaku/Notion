## Deutsch

Dieser Ordner enthält das Investorenpaket **„Eine Stimme, drei Produkte“** für ein Portfolio-Investment von **500.000 €** in Aybal, LiveFX und die Buchreihe „Mein neurodiverser Kompass“.

| Datei | Inhalt |
|---|---|
| `index.html` | Übersichtsseite mit Umschalter DE/TR/EN; verlinkt alle Unterlagen und die Projektmaterialien (`../aybal-show/`, `../live-fx/business/`, `../deniz-trailer/`, `../deniz-teen/`) |
| `PORTFOLIO.de.md` / `.tr.md` / `.en.md` | Investment-Memo: These, Projekte mit Quellen, Synergien, Angebot mit vorgeschlagener Aufteilung, Struktur-Optionen, 24-Monats-Meilensteine, Risiken, Team, Kontakt |
| `Portfolio_Investor_Deck_DE.pptx` / `_TR` / `_EN` | Pitch-Deck, 12 Folien |
| `OnePager_DE.pdf` / `_TR` / `_EN` | Eine Seite A4 zum Versenden |
| `build-deck.js` + `deck-content.{de,tr,en}.json` | Generator für die Decks (pptxgenjs): `node build-deck.js` |
| `build-onepager.js` | Generator für die One-Pager (Playwright): `node build-onepager.js` |

**Vor dem Versand:** Die Aufteilung (250.000 € / 200.000 € / 50.000 €) ist ein **Vorschlag – bitte bestätigen**. Platzhalter `[Name]`, `[E-Mail]`, `[Telefon]`, `[Zahl]`, `[offen]`, `[Datum]` ausfüllen. Struktur (Holding, SPVs, Hybrid) mit Rechts- und Steuerberatung klären. Aybal-Zahlen sind unverändert aus `aybal-show/Aybal_Investor_Deck.pptx` übernommen.

## English

This folder holds the **“One voice, three products”** investor package for a **€500,000** portfolio investment in Aybal, LiveFX and the “My Neurodivergent Compass” book series.

| File | Contents |
|---|---|
| `index.html` | Overview page with a DE/TR/EN switcher; links every document and the project materials |
| `PORTFOLIO.de.md` / `.tr.md` / `.en.md` | Investment memo: thesis, sourced project profiles, synergies, offer with proposed split, structure options, 24-month milestones, risks, team, contact |
| `Portfolio_Investor_Deck_DE.pptx` / `_TR` / `_EN` | 12-slide pitch deck |
| `OnePager_DE.pdf` / `_TR` / `_EN` | One A4 page to send ahead |
| `build-deck.js` + `deck-content.{de,tr,en}.json` | Deck generator (pptxgenjs): `node build-deck.js` |
| `build-onepager.js` | One-pager generator (Playwright): `node build-onepager.js` |

**Before sending:** the split (€250,000 / €200,000 / €50,000) is a **proposal – please confirm**. Fill in the placeholders `[Name]`, `[email]`, `[phone]`, `[number]`, `[open]`, `[date]`. Settle the structure (holding, SPVs, hybrid) with legal and tax advisers. Aybal figures are taken unchanged from `aybal-show/Aybal_Investor_Deck.pptx`.
